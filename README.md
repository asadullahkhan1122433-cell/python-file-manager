# Python File Manager – CRUD Operations

## About
A beginner-friendly Python project that performs CRUD (Create, Read, Update, Delete) operations on files using Python's `pathlib` module.

## Features
- Create new files and write content.
- Read existing file contents.
- Rename files.
- Overwrite existing content.
- Append new content.
- Delete files with confirmation.
- List files and folders.
- Interactive command-line menu.

## Technologies Used
- Python 3
- pathlib
- File Handling
- Exception Handling

## How to Run

1. Install Python 3.
2. Clone this repository.
3. Open the project directory.
4. Run:

```bash
python file_manager.py
```
